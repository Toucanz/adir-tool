# adir-tool

Repo containing code for the autism diagostic interview report generation tool

To intall, ensure you have python 3.12.2 installed and added to PATH.

Open a terminal, and make sure it's pointed to the base repo directory (shift + ' in VSCODE)

Execute the setup_env script. The .sh file is for linux, the .bat file is for windows. This will install all the dependencies needed

Every time you want to work on this, make sure you activate the venv to maintain consistentcy with library versions.
